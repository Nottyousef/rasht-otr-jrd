# جرد رشة عطر

برنامج جرد الزجاج والعطور في البيت والمصنع والمحل. صفحة ويب تشتغل من المتصفح وتتثبت على التلفون مثل التطبيق.

## الرفع على GitHub Pages

1. سو مستودع جديد في GitHub (لازم يكون Public في الحساب المجاني).
2. ارفع كل الملفات والمجلدات اللي هني مثل ما هي: index.html و sw.js و manifest.webmanifest و jspdf.umd.min.js ومجلد fonts ومجلد icons.
3. من Settings ثم Pages اختار Deploy from a branch، والفرع main، والمجلد root، واضغط Save.
4. بعد دقيقة تقريباً يطلع لك رابط الموقع بنفس الصفحة.

## التثبيت على التلفون

افتح الرابط بالتلفون، وبعدها من قائمة المشاركة أو قائمة المتصفح اختار "إضافة إلى الشاشة الرئيسية".

## مهم

1. الأرقام تنحفظ تلقائياً على نفس الجهاز فقط. التلفون والكمبيوتر كل واحد له أرقامه.
2. خذ نسخة احتياطية من تبويب الملخص بعد كل جرد. نفس الملف تقدر ترجعه على أي جهاز ثاني.
3. المستودع عام، يعني أسماء الأصناف تنشاف لأي أحد عنده الرابط. الأرقام ما تنرفع ولا تطلع من جهازك.
4. البرنامج يشتغل بدون إنترنت بعد أول فتح.
